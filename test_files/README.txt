Credit Application Test Set
===========================

9 synthetic two-page credit application PDFs.

Cases 01-03: embedded-text PDFs
Cases 04-06: scanned/image-only PDFs
Cases 07-09: mixed PDFs (page 1 embedded text, page 2 scanned image)

All documents use fictional data.
Each case contains 32 varying values: 2 metadata fields plus 30 evaluated fields.
Use ground_truth.json as the reference for field-level accuracy scoring.
